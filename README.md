# tuuh-6

6-р ангийн түүхийн цахим хичээлийн сайт: богино хичээлийн картууд, 3 төрлийн тоглоомон тест, оноо ба тэмдэг, багшийн самбар.
Нэвтрэх хэсэг, багшийн самбар, өгөгдлийн давхарга нь **Амжилт** сайтын код дээр суурилсан (React + Vite + Supabase).

## Ажиллуулах

```bash
npm install
npm run dev        # http://localhost:5173
npm run check      # хичээлийн агуулгын бүтцийг шалгана
npm run build      # dist/ хавтсанд бэлтгэнэ
```

`.env` файл байхгүй бол апп **демо горимоор** ажиллана: өгөгдөл зөвхөн тухайн хөтөч дээр хадгалагдана. Демо горимд багшаар бүртгүүлэх код нь `BAGSH2026`.

## Сургуульд байршуулах (үнэгүй)

1. **Supabase** (supabase.com → New project). Амжилтынхаас **тусдаа** шинэ төсөл нээнэ.
   - SQL Editor → `supabase/schema.sql`-ийг бүтнээр нь ажиллуулна.
   - `app_settings` хүснэгтийн `teacher_code`-ийг нууц кодоор солино. Багш нар бүртгүүлэхдээ энэ кодыг ашиглана.
   - Authentication → Providers → Email → **Confirm email**-ийг унтраана. Сурагчид утасны дугаараар бүртгүүлдэг тул имэйл баталгаажуулах боломжгүй.
   - Project Settings → API хэсгээс `URL` болон `anon key`-г хуулж авна.
2. **Vercel** (vercel.com → Import Git Repository → `tuuh-6`):
   - Environment Variables: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`.
   - Deploy.

## Агуулга нэмэх

Бүх хичээл `src/content/grade6.js` файлд байна. Сэдэв бүр:

| Талбар | Юу байна |
|---|---|
| `cards` | Богино хичээлийн картууд: `{ emoji, title, text }` |
| `questions` | Сонгох тест: `{ q, o: [...хувилбар], a: зөв хариуны индекс, e: тайлбар }` |
| `match` | Холбох тоглоом: `{ prompt, pairs: [{ l, r }] }` |
| `order` | Он цагийн дараалал: `{ prompt, items: [...] }`. **Зөв дарааллаар** бичнэ, апп өөрөө холино. |

`match`, `order` заавал биш. Байхгүй бол тухайн тоглоом гарахгүй. Нэмсний дараа `npm run check`-ээр шалгана.
Багш нар сонгох асуултыг апп доторх "Асуулт нэмэх" хэсгээс ч нэмж болно.

## Оноо ба тэмдэг

Дүрмүүд нь `src/lib/score.js` файлд байна. Бүх оноог оролдлогуудаас тооцдог тул тусдаа хүснэгт хэрэггүй.

- Зөв хариулт бүрт +10 оноо. 3 ба түүнээс олон дараалан зөв хариулбал хариулт бүрт +5.
- Тестэд 100% авбал +20. Хичээлийн картуудыг дуусгавал +20. Багшийн даалгаврыг хийвэл +10.
- Нэг тестийг олон удаа өгвөл хамгийн өндөр оноо нь тоологдоно.
- 6 зэрэг (🌱 Шинэ судлаач → 👑 Түүхийн мэргэн), 8 тэмдэг.
